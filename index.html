Seu acesso é restrito aos médicos do CTI, podendo ser utilizado fora do hospital exclusivamente para fins de continuidade assistencial, revisão clínica e tomada de decisão, sendo vedado o compartilhamento de informações, o armazenamento local de dados ou o acesso por terceiros, em respeito ao sigilo e à confidencialidade das informações de saúde.

🏥 1. Admitir Paciente

  1. Clique no leito desejado acima

  1. Vá para aba 📊 Passômetro Diário
  2. Clique + NOVO DIA para criar evolução
  3. Preencha: diagnósticos, sinais vitais, exames, medicamentos, conduta

☀️ 3. Consolidado (Copiar)

  1. No card de cada dia, clique ☀️ CONSOLIDADO DIA ou 🌙 NOITE

  1. Use o botão 🖨️ Imprimir no cabeçalho

  5. Escolher Dia — selecione qual dia imprimir
  6. Exames — passograma em paisagem A4
  7. A fonte ajusta automaticamente para caber na folha

  1. Aba 🔬 Passograma — grade de exames por dia

  3. Use ⚡ Entrada Rápida para lançar exames de uma vez
  4. Imprime em folha A4 paisagem

  1. 📄 Sumário Alta — documento de alta CTI

  5. 🔄 Transferir Leito — move entre boxes

💊 GUIA RÁPIDO: Prescrição no SPDATA

▼

🏥 CUIDADOS GERAIS (sempre prescrever):

✓ Dieta (especificar tipo: zero, enteral, parenteral)
✓ Sinais vitais - contínuo (monitor)
✓ Comunicar anormalidades - contínuo
✓ Cabeceira elevada 60° - contínuo
✓ Glicemia capilar - inicialmente 4/4h (ajustar conforme controle)
✓ Oxigenoterapia (se necessário: O2 sob cateter, VM, VNI)

💊 ANALGESIA E CONFORTO:

✓ Analgésico/Antitérmico via IV (primeira linha)
✓ Analgésico/Antitérmico via VO/SNG (alternativa)
✓ Antiemético primeira linha
✓ Antiemético segunda linha (se refratário)

🛡️ PROFILAXIAS (avaliar indicação):

✓ TEV: Heparina de baixo peso molecular ou não-fracionada
✓ Gástrica: Inibidor de bomba de prótons ou antagonista H2
✓ Ocular: Lubrificação (se indicado: sedação, coma)

⚕️ MEDICAMENTOS ESPECÍFICOS (conforme necessidade):

✓ Medicamentos de uso contínuo do paciente - REVER NECESSIDADE RIGOROSAMENTE (ajustar doses, via, interações)
✓ Sedoanalgesia (se VM ou agitação): Opioide + Benzodiazepínico ou Hipnótico (titular conforme RASS)
✓ Vasopressores (se choque): Catecolamina de escolha (titular para PAM ≥ 65 mmHg)
✓ Antibioticoterapia (se infecção): Empírico até culturas, ajustar conforme antibiograma

⚠️ ATENÇÃO: Revisar TODOS os medicamentos de uso domiciliar. Suspender temporariamente drogas não essenciais. Ajustar doses renais/hepáticas. Verificar interações medicamentosas.

💡 DICA: No SPDATA, use a função "Prescrição Padrão CTI" se disponível. Sempre individualizar conforme o paciente. Documentar justificativa de mudanças na evolução.
